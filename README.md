# TerraLearn 🌍

> Interactive 3D Earth globe web application for geography exploration and learning.

## Overview

TerraLearn is a client-side 3D globe application designed to visualize physical and political geographical features, explore true spherical proportions without Mercator map distortion, and reinforce knowledge through gamified blind-map quizzes.

## Tech Stack

- **Core:** TypeScript (Strict), Vite
- **3D Engine:** Globe.gl, Three.js
- **Spherical Geometry:** d3-geo
- **Styling:** Modern Vanilla CSS Design Tokens (Dark-first aesthetics)
- **Testing:** Vitest, Playwright

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Run quality checks (typecheck, lint, test)
npm run check

# Build production bundle
npm run build
```
